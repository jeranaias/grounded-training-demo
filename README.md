# Grounded Training — interactive showcase

A self-contained, **offline** demo of a grounded AI training platform: cited lessons,
grounded diagrams, a confidence-graded quiz, a branching applied scenario, an "ask the
doctrine" reference, and an aggregate class-gap view — on real rifle-marksmanship doctrine
(TC 3-22.9, a public U.S. Army publication).

**Live demo:** https://jeranaias.github.io/grounded-training-demo/

Every claim is cited to the source paragraph, and the AI **refuses** to answer what the
source doesn't support — the trust property that makes AI adoptable in a schoolhouse. This
page runs entirely in the browser (offline showcase mode); the production system pairs the
[Anchor](https://github.com/jeranaias/anchor) grounding engine (open-source, Apache-2.0)
with an LMS surface.
